# Notices and source lineage

OLCRTC Android is an unofficial derivative distribution.

## Android application

Based on [SagerNet/sing-box-for-android](https://github.com/SagerNet/sing-box-for-android), copyright 2022 nekohasekai and contributors. Distributed under GPLv3 and the additional naming and association condition contained in [LICENSE](LICENSE).

## Core

The packaged core is based on [shtorm-7/sing-box-extended](https://github.com/shtorm-7/sing-box-extended), which is a fork of the original [SagerNet/sing-box](https://github.com/SagerNet/sing-box). The exact corresponding source for this release is [Shtorm-glitch/sing-box-extended tag v1.13.11-extended-2.1.0-olcrtc.1](https://github.com/Shtorm-glitch/sing-box-extended/tree/v1.13.11-extended-2.1.0-olcrtc.1).

## OLCRTC

OLCRTC is based on [openlibrecommunity/olcrtc](https://github.com/openlibrecommunity/olcrtc). The exact corresponding source is [Shtorm-glitch/olcrtc tag v0.0.1-olcrtc.1](https://github.com/Shtorm-glitch/olcrtc/tree/v0.0.1-olcrtc.1).

## LiveKit SDK

The OLCRTC source uses a minimal fork of [livekit/server-sdk-go](https://github.com/livekit/server-sdk-go). The exact corresponding source is [Shtorm-glitch/server-sdk-go tag v2.16.4-olcrtc.1](https://github.com/Shtorm-glitch/server-sdk-go/tree/v2.16.4-olcrtc.1).

No upstream project endorses or supports this derivative release.
